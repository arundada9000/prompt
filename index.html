Quick guide

1. Set the scene

Enter your project name, type, and a short description. Project type controls which sections appear (e.g. PWA reveals a dedicated section).

2. Pick requirements

Tick the checkboxes you want in the prompt. Use the sidebar checkboxes to select or clear an entire section at once. Dropdowns and text fields tune exact values (Python 3.12, Vite + React, LCP under 2.5s, etc.).

3. Review the prompt

The generated prompt updates live. Copy it, download as Markdown/JSON/YAML/TXT, or expand it fullscreen. Undo/redo fixes mistakes; keyboard shortcut ? lists every shortcut.

4. Reuse your work

Save presets for standard stacks, restore past versions from history, paste an old prompt to auto-match requirements, or share a URL snapshot. Everything is stored locally in your browser.
