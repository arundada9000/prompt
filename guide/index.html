The Prompt Architect guide

How to assemble, tune, export, and reuse precise development prompts for AI coding assistants.

Prompt Architect turns reusable requirements into one clean, production-ready development prompt. This guide covers the full workflow, from first click to repeatable presets.

Start with the project card

Give the project a name and the surface type on the left. The type may reveal extra sections (choose PWA and the platform section appears by itself). Type a quick description of what you are building, then select a tech stack from the dropdowns. Each dropdown shows a short rationale under the select.

  • Name and type are always included in the output.
  • Description is free text; the assistant treats it as context, so write full sentences.
  • Dropdowns give you presets only, with rationale shown for each.

Mark requirements across the sections

The sidebar lists all sections with a running count. Each checkbox is a requirement the generated prompt states verbatim. There is no wrong combination, but fewer, precise boxes often outperform a wall of boxes.

  • Use 'Select all' in a section when it fully applies.
  • Balance rule-style boxes (no em dashes) with fact-style dropdowns (Vite + React).
  • Check the workflow section so the assistant plans, tracks, and commits properly.

Reviews and previews

The preview pane updates live in Markdown by default. Switch to JSON or YAML for pipelines and config-heavy tools. Use fullscreen to inspect long prompts before exporting.

  • Markdown for chat assistants, JSON for automation, YAML for config lovers.
  • Fullscreen (`Ctrl/Cmd + Shift + F`) helps you read the whole brief.
  • The character count in the footer is a rough context-window sanity check.

Export, copy, and save

Copy to clipboard or download the prompt. Save any combination as a preset, and export your presets as a JSON file to back them up or move machines.

  • Paste and match lets you re-import an older prompt to restore all selections.
  • Every good run belongs in your repository next to the code it generated.
  • The footer counter tracks how many prompts you have generated.

History, undo, and sharing

Prompt history keeps the last 20 generated prompts, undo/redo covers the last 50 edits, and any configuration fits in the URL hash for sharing.

  • Open history with `Ctrl/Cmd + Shift + H` to recall any generated prompt.
  • Supply the full URL and the recipient sees the same selections.
  • Search filters every section, checkbox, dropdown, and text field at once.

Five habits that raise prompt quality

  1. Be explicit about the outcome; every sentence narrows the space of plausible-but-wrong outputs.
  2. Use dropdowns for facts and checkboxes for rules.
  3. Prevention beats correction: state what not to do before it happens.
  4. Iterate weekly and tighten one section at a time.
  5. Read the output like a reviewer, not like a user.
